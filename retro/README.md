# Retro recommendations

One file per process-change proposal, written by `/sdlc:retro` from
`templates/retro.md` and named `YYYY-MM-DD-<slug>.md`.

Each one is the document a change advisory board reads: cited evidence, findings, the
proposed diff, repos affected, risk, rollback, and eval results. The board records its
decision in the same file, so this directory is the process's own decision history.

Reports live here rather than in the product repo they came from, so a board reviewing a
proposal sees the recommendation and the diff side by side in one pull request.
